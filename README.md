# 山东药师学习助手

面向 `training.sdlpa.org.cn` 继续教育页面的独立 Edge 扩展和用户脚本，采用 MIT 许可证。项目与山东省药师协会、OCS 及 AI 服务商无隶属关系。

支持播放控制、静音、拖动面板、普通签到弹窗处理、读取平台“已完成”标记后切换未完成课件，以及使用自选接口的可选 AI 练习辅助。AI 默认关闭，用户自行配置模型和 Key；接口可能收费，答案可能有误。最终交卷、评价及身份验证由用户操作。

扩展不修改平台计时或完成记录、不加速视频、不读取登录 Cookie。平台规则和浏览器后台节流仍可能影响计时；本项目不保证获得学分或考试通过。提前切换可能跳过尚未出现的末尾练习，如需完整观看，请关闭“提前切换”。

## 安装与状态

当前修复版本：0.5.2，提供用户脚本和本地扩展包。0.5.1 于 2026-10-20 提交 Edge Add-ons 认证；商店当前状态以 Partner Center 为准，0.5.2 尚未提交商店。

0.5.2 修复：AI 填写完成后再开启“下一题”也能继续；等待延迟出现或暂时禁用的下一题按钮；逐项核对多选结果后才继续；同一题不重复点击或再次请求 AI。主面板增加“AI 填写后继续下一题（不交卷）”，默认关闭，需要用户开启并点击“开始”。手动仅勾选一项不作为答题完成依据；最终交卷仍由用户操作。面板显示真实版本号。

本地开发安装：构建后在 Edge 扩展页开启开发人员模式，选择“加载解压缩的扩展”，打开 `work/extension-staging/山东药师助手`。加载后刷新课程页。使用此方式时，未来商店版本需要另行安装；两者设置不会自动迁移。

用户脚本位于 `outputs/sdlpa-helper.user.js`，可导入支持 GM 存储和跨域请求的脚本管理器；不要与扩展同时启用。

本地核心检查 52 项、扩展适配检查 9 项已通过。最新版扩展尚待真实页面复测；旧版用户脚本的实课记录不等于本版验收。打包成功不等于微软认证通过。

## 构建与检查

需要 Node.js 18 或更新版本、Python 3，以及 npm。

```sh
npm ci --prefix work/test-env
npm run build
npm test
npm run package
```

`npm run build` 从用户脚本和 `work/extension-src` 生成扩展；`npm run package` 先检查，再生成根目录含 manifest.json 的商店 ZIP。打包结果位于 `outputs/Edge商店发布材料`。运行时不依赖 npm 或 Python；依赖只用于开发和测试。

## 隐私与支持

设置与 API Key 保存在浏览器本机扩展存储中，不额外加密。开启 AI 后，当前题干、选项和认证信息直接发送到用户选择并授权的接口；接口测试也会发送通用测试请求。没有开发者分析或广告服务器。详见 [隐私政策](https://sx050907-png.github.io/sdlpa-learning-helper/privacy.html)。

公开支持邮箱：sempre0011@hotmail.com。也可以在本仓库提交 Issue；请勿附上密码、API Key、登录会话或学员个人信息。

## 更新与贡献

正式上架后，维护者应在同一个 Edge 商店产品下提高版本号、上传新版并完成认证。商店安装用户由 Edge 分发更新；已打开课程页需刷新。开发目录加载的用户不参与商店自动更新。

更改功能时同步维护用户脚本、扩展源文件、隐私政策和测试。提交前运行检查；涉及平台交互的改动还需授权的真实页面测试。请勿提交真实账号、密钥、课程视频或含个人信息的截图。
