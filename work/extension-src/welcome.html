山东药师学习助手

安装一次，以后打开课程就能使用。无需 OCS、油猴、Node.js 或 Python。

从 Edge 商店安装与更新

首次从 Microsoft Edge Add-ons 安装后，后续版本通过同一商店条目发布并由 Edge 分发更新。已打开的课程页在扩展更新后需要刷新，才能运行新版页面助手。

从本地加载版或脚本版迁移到商店版时，请停用旧版并刷新课程页。首次迁移的设置可能需要重新填写；之后同一商店扩展的版本更新沿用本地设置。商店尚未发布时，可使用下面的本地安装方式进行测试。

本地安装包（开发测试）

  1. 把收到的压缩包完整解压，放在一个以后不会删除或移动的文件夹。
  2. 在 Edge 右上角“…” →“扩展”→“管理扩展”，打开开发人员模式。
  3. 点击加载解压缩的扩展，选择压缩包里的 山东药师助手 文件夹（里面有 manifest.json）。
  4. 若以前装过脚本版，在脚本管理器里停用“山东药师继续教育助手”，然后刷新课程页。OCS 中同一平台的自动操作也请停用。

本地加载方式不接收商店更新，需要开发者自行替换文件并重新加载；希望自动更新的用户应在正式上架后从商店安装。不要删除本地已加载的文件夹。

开始学习

  1. 打开继续教育平台，登录自己的账号并进入课程。
  2. 在右下角蓝色助手中点击开始。按住标题栏可拖动，点“−”可收起。
  3. 保持电脑联网且不休眠，建议课程页保持前台可见，避免后台节流影响平台计时。右侧课件显示“已完成”且稳定确认后，助手选择未完成课件，不要求视频自然结束；仅显示 100% 不算完成，当前签到或练习弹窗仍优先处理。
  4. “平台显示‘已完成’后提前切换”默认开启，关闭后等待视频自然结束。若需观看尚未出现的末尾练习，请关闭提前切换。勾选“静音播放”可静音并保存，后续课件沿用，不改变音量滑块或速度。
  5. 需要暂停时点击助手的停止。身份验证、扫码验证、最终交卷和课程评价由你完成。

可选：启用自己的 AI 接口

  1. 展开课程助手中的“AI 接口与练习设置”，选择服务商，填写模型及自己的 Key，然后保存设置。不要把 Key 发给别人。
  2. 点击 Edge 工具栏里的助手图标（若没看到，先在拼图形状的“扩展”菜单中找到它），点击授权已保存的 AI 接口并确认。
  3. 回到课程助手，点击测试接口。成功后按需要启用 AI 识别、填写及随堂小测提交。

支持智谱、豆包、DeepSeek、OpenAI，以及兼容 Chat Completions 格式的自定义 HTTPS 接口。单次请求等待最多 25 秒，不会自动重试扣费。AI 答案需你核对，课后测验的最终交卷需你操作。

数据与权限

默认只在 training.sdlpa.org.cn 运行。设置和 Key 保存在本机扩展存储，不同步到云端。AI 仅将当前题目、选项及 Key 发到你保存并授权的接口；手动测试接口时发送通用测试题。不读取登录 Cookie，不上传视频，不伪造计时或学习进度。没有后台常驻页面，关闭课程后不再扫描页面。阅读完整隐私说明。

卸载与回退

在 Edge“管理扩展”中移除此助手即可。扩展与脚本版的配置分别保存，不会自动迁移 Key。如需回到脚本版，先停用或移除此扩展，再启用原脚本并刷新课程。

升级时，把新版文件覆盖到原来的“山东药师助手”文件夹，在 Edge“管理扩展”中点击该扩展的重新加载按钮，再刷新课程页。保留原文件夹位置和同一浏览器配置文件，原设置可继续使用。

本工具为独立辅助工具，与山东省药师协会无隶属关系。请按平台要求完成学习。
