山东药师学习助手隐私说明

生效日期：2026-10-20。适用于本扩展及其页面内助手。发布者以 Microsoft Edge Add-ons 中本扩展的发布者信息为准。公开支持邮箱：sempre0011@hotmail.com。本扩展为独立工具，与山东省药师协会及 AI 服务商无隶属关系。

页面内处理

扩展仅在 training.sdlpa.org.cn 的页面内读取课件标题、时长、完成标记、播放器状态、可见提示及可见练习题和选项，用于提供播放控制、静音、课件切换、普通签到及可选练习辅助。它不读取浏览历史、登录 Cookie 或浏览器保存的密码，不录制或上传音视频，不修改平台计时与完成记录。

本机保存

扩展将功能开关、面板位置及你填写的接口地址、服务商、模型名称和 API Key 保存在浏览器本机扩展存储中，不使用云同步。API Key 在课程页助手的密码输入框中配置；本地保存不等于额外加密，也不使用操作系统密钥库。普通播放状态和题目不会作为使用日志存入开发者服务器；本扩展没有开发者运行的分析、广告或题库服务器。

可选的 AI 请求

AI 自动辅助默认关闭。你填写接口信息、授权目标接口并启用 AI 后，扩展会把当前可见题干、选项、题型及必要的请求指令发送至你指定的服务商；API Key 仅用于该接口的认证头。手动点击“测试接口”也会发送请求，但使用通用测试题，不使用课程题目。不主动发送账号姓名、学员标识、整页内容或视频。

接收方可能是你选择的智谱、豆包、DeepSeek、OpenAI、自定义服务商或本机服务。远程接口要求 HTTPS；localhost、127.0.0.1、::1 本机接口可使用 HTTP。服务商会看到连接 IP、认证及请求内容，并可能根据其自己的条款保留数据和收取模型调用费用；请阅读所选服务商的隐私政策。本扩展不向开发者服务器转发这些请求。

关闭、删除和保留

取消“启用 AI”后，不再发起新的自动解答，尚未完成请求的回复也不会继续填写或提交答案。已经发送给服务商的数据无法由扩展撤回；服务商侧删除请求须联系该服务商。手动点击“测试接口”属于单独的请求操作。

需要删除本机 Key 时，清空 API Key 输入框并点击“保存设置”。其他配置可在助手中修改；移除本扩展会移除其本机扩展存储。设置保留到你修改、清除或移除扩展，不设置单独的到期时间。卸载后服务商侧的既有数据不受影响。

权限

storage 用于保存上述本机设置。课程站点访问用于运行页面助手。可选 HTTPS 和本机接口访问只在你通过扩展窗口授权某个接口后用于 AI 请求，不自动授予所有网站权限。没有摄像头、麦克风、浏览历史、广告跟踪或下载视频权限，不出售或用于广告分析你的数据。

变更与联系

功能和隐私说明随扩展版本一同更新；需要新权限时由浏览器提供权限确认。疑问或数据请求可通过商店页面中该扩展的公开支持联系方式提出。
